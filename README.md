# TP-PizzerIA-Labo-2

La idea general del proyecto PizzerIA es desarrollar un sistema en Python para una pizzería que permita gestionar pedidos,   controlar el stock de ingredientes, consultar precios de proveedores y generar reportes de ventas. 
El sistema simula el funcionamiento real de una pizzería: los clientes realizan pedidos, la cocina los procesa, el inventario se actualiza automáticamente y al final se generan informes con datos importantes como productos más vendidos, total recaudado y stock restante. Además, el proyecto integra los principales temas vistos en Laboratorio de Computación II, como POO, Pandas, ETL, generadores, decoradores, requests, threading, asyncio y multiprocessing.
